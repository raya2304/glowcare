# GlowCare – Skincare Store

GlowCare is a modern and responsive one-page skincare store website built with **HTML, Tailwind CSS, and JavaScript**. It provides a clean shopping experience for browsing skincare products and exploring simple skincare routines.

## Features

* Responsive one-page design
* Skincare product collection
* Product category filtering
* Product search functionality
* Add to Bag functionality
* Interactive shopping bag modal
* Skincare routine section
* Customer reviews section
* Newsletter subscription
* Mobile-friendly layout
* Clean and minimal UI

## Technologies Used

* HTML5
* Tailwind CSS
* JavaScript
* DOM Manipulation

## Product Categories

* Cleansers
* Serums
* Moisturizers
* Sunscreens

## JavaScript Functionality

The project uses JavaScript to provide interactive features such as:

* Searching products
* Filtering products by category
* Adding products to the shopping bag
* Removing products from the bag
* Updating the bag item count
* Opening and closing the shopping bag
* Newsletter subscription validation

## Project Structure

```text
GlowCare-Skincare-Store/
│
└── index.html
```

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No additional installation is required.

## Purpose

This project was created to practice frontend development concepts including responsive layouts, Tailwind CSS, JavaScript events, DOM manipulation, product filtering, search functionality, and dynamic UI updates.
